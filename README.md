# 时空错位：相对论漫游

> 一款用「玩法即物理原理、谜题即知识点」打造的 2D 横版相对论解谜游戏。

玩家扮演**时空观测员**，在碎片化的块状宇宙中修复时空裂隙，沿着 _狭义相对论 → 广义相对论 → 量子引力 → 熵与时间本质_ 四大世界逐步建立对相对论的直觉理解。

**核心准则**：玩家在解开谜题的瞬间，应该已经直觉性地理解了背后的物理。

> 🎮 **[点此在线试玩（浏览器直接运行，无需下载）](https://moss-550-w.github.io/Relativity-Puzzle/)**

## 游戏特色

| 设计铁律 | 说明 |
|---|---|
| **玩法 = 物理原理** | 所有机制源自相对论真实结论，不编造科幻设定 |
| **操作即时响应** | 时间膨胀绝不延迟玩家输入，仅通过画面与场景时钟表达 |
| **失败无惩罚** | 谜题可随时重置，无死亡惩罚、无资源枯竭、无软锁 |
| **科普隐于玩法** | 无大段说教，靠图鉴短句 + 动态演示，会玩就会懂 |
| **无战斗 / 无血量 / 无升级** | 唯一的成长是「理解」，能力由关卡机制赋予 |

- **4 个世界 · 11 个关卡 + 1 个 BOSS**，约 3–4 小时流程
- **3 个趣味小游戏**：光钟工坊、虫洞工程师、麦克斯韦妖
- **2 处隐藏彩蛋**：双生子小屋、物理学家小屋（爱因斯坦 & 霍金对话）
- **时空图鉴系统**：23 物理词条，各配极简几何图标，随解谜逐步解锁
- **动态程序化配乐**：实时合成的三层旋律，四世界各有调式与情绪，速度/引力/熵直接驱动节奏与崩解
- **三种结局**：由玩家的全程行为统计触发，无显式选择按钮

## 操作说明

| 输入 | 动作 | 获得时机 |
|---|---|---|
| `A` `D` / `←` `→` | 左右移动，长按持续累积加速 | 初始 |
| `W` / `空格` | 跳跃 | 初始 |
| `Left Shift` | 冲刺（加速累积速率 ×3.5） | 初始 |
| 二段跳 | 空中再次跳跃 | 克尔黑洞 BOSS 关持久解锁 |
| `F` | 抓取 / 拖拽（虫洞口、卡西米尔板） | 世界 2 起 |
| `E` | 观测（延长量子裂隙）/ 与 NPC 交谈 | 世界 3 起 |
| `R` | 重置当前谜题 | 全程可用 |
| `ESC` | 暂停菜单 / 返回 | 全程可用 |

**速度累积**：长按方向键 → 目标速度持续增长（上限 980 px/s ≈ 0.98c）→ 触碰光速红线（990 px/s = 0.99c）触发弹回。速度越高，场景时间流速越快、画面横向尺缩、色调蓝移。

| M3-3 | 时序保护 | 时序保护猜想，阻止宏观时间旅行 |

| 层级 | 主题 | 关键机制 |
|---|---|---|
| 上层 | 熵之斜坡 | 全局熵增驱动平台崩解 |

### 趣味小游戏

## 核心物理机制

游戏所有时间效应由全局单例 `TimeManager` 统一管理，铁律是**玩家输入永远使用实时 delta，场景物体使用时间膨胀后的 delta**。

```
有效时间流速 = 场景速度膨胀(洛伦兹因子) × 引力膨胀因子 × 局部时间缩放
```

| 世界 | 物理公式 | 实现 |
|---|---|---|
| W1 速度-时间 | 洛伦兹因子 γ = 1/√(1 − v²/c²) | `speed_time_coupling.gd` |
| W2 引力-时间 | √(1 − 2GM/rc²)，事件视界内时间停滞 | `gravity_time_dilation` / `gravity_zone.gd` |
| W3 量子裂隙 | 出现前 0.5s 预兆粒子，观测可延长存续 | `quantum_fissure.gd` |
| W4 熵增 | 全局熵 [0,1] 线性递增，驱动崩解 | `entropy_system.gd` |

物理准确性以 `docs/physics-reference.md` 为准；假说性内容均标注「非科学实证」。

## 结局系统

结局**不通过选择按钮触发**，而由 `PlayerMetrics` 全程追踪的行为统计决定：

| 结局 | 触发条件 |
|---|---|
| 本源顿悟 | 在底层静止空间停留 > 60s 且熵减干预 < 3 次 |
| 闭环囚笼 | CTC 回溯 ≥ 3 次 |
| 奔赴未来 | 修复时空碎片 ≥ 3 个（默认走向） |

## 运行与开发

### 在线游玩（推荐）

浏览器直接打开，无需安装：

**https://moss-550-w.github.io/Relativity-Puzzle/**

每次推送 `main` 分支，由 GitHub Actions 自动导出 Web 版并部署到 GitHub Pages（工作流见 `.github/workflows/deploy-pages.yml`）。

### 环境要求
- [Godot Engine 4.4+](https://godotengine.org)（项目当前基于 4.6，GL Compatibility 渲染后端）

### 运行
1. 用 Godot 打开项目根目录的 `project.godot`
2. 按 `F5` 运行，或直接运行主场景 `scenes/ui/main_menu.tscn`

### 命令行运行
```bash
# 编辑器内运行
godot --path .

# 无头模式运行某个场景（调试用）
godot --headless res://scenes/minigames/wormhole_engineer.tscn
```

### 技术栈
- **引擎**：Godot 4.6（GDScript）
- **渲染**：GL Compatibility（兼容低端设备）
- **美术**：程序化绘制（`_draw` / `Polygon2D`）+ 自定义着色器 + 中央调色板统一配色 + 四世界差异化背景网格
- **音频**：程序化合成 — 动态背景音乐（按世界切换调式 + 物理联动）+ 10 种音效
- **分辨率**：1280×720，canvas_items 拉伸

## 项目结构

```
Relativitygame/
├── project.godot              # 工程配置（含 7 个全局单例注册）
├── scenes/
│   ├── ui/                    # 主菜单、选关、HUD
│   ├── world_1_lorentz/       # 世界1：狭义相对论
│   ├── world_2_gravity/       # 世界2：广义相对论 + 克尔黑洞 BOSS
│   ├── world_3_quantum/       # 世界3：量子引力
│   ├── world_4_entropy/       # 世界4：熵之终焉（三层）
│   └── minigames/             # 光钟工坊、虫洞工程师、麦克斯韦妖
├── scripts/
│   ├── autoload/              # 全局单例（GameState/TimeManager/EntropySystem 等）
│   ├── player/                # 玩家移动、光晕、能力
│   ├── mechanics/             # 核心物理机制
│   ├── objects/               # 交互物件（虫洞口、平台、碎片等）
│   ├── npc/                   # 双生子、爱因斯坦&霍金 NPC
│   ├── ui/                    # 图鉴、HUD、相对时钟、世界背景、转场
│   └── palette.gd             # 中央调色板（配色唯一真源）
├── resources/codex_entries/   # 图鉴词条数据
├── assets/shaders/            # 时间扭曲等着色器
└── docs/                      # 设计文档、物理参考、术语表
```

### 全局单例（Autoload）
| 单例 | 职责 |
|---|---|
| `GameState` | 世界/关卡注册表、进度、解锁、谜题重置 |
| `TimeManager` | 全局时间中枢：速度膨胀 × 引力膨胀 |
| `EntropySystem` | 世界4 全局熵增与秩序资源 |
| `PlayerMetrics` | 行为追踪 → 结局判定 |
| `CodexManager` | 图鉴解锁管理 |
| `AudioManager` | 程序化合成：动态背景音乐 + 音效播放 |
| `TransitionLayer` | 场景淡入淡出转场 |

## 一、设计铁律

以下原则为不可妥协的基石，所有设计决策必须回溯到这些条款：

| 编号 | 原则 | 说明 |
|------|------|------|
| **P1** | **玩法 = 物理原理** | 所有机制必须源自相对论真实结论，不编造科幻设定。谜题即知识点。 |
| **P2** | **操作即时响应** | 任何时间效应不得影响玩家输入的实时反馈。通过画面、动画、场景时钟表达时间膨胀，绝不对玩家操作引入延迟。 |
| **P3** | **失败无惩罚** | 谜题重置即时、无死亡惩罚、无资源枯竭死局。玩家永远可以重试。 |
| **P4** | **科普隐于玩法** | 无弹出大段文字。图鉴提供短句解释 + 动态示意图。玩家解开谜题的瞬间，已经直觉性地理解了相对论。 |
| **P5** | **无战斗、无血量、无升级** | 唯一成长是"理解"。角色能力由关卡机制赋予，无经验值、无技能树。 |

## 二、世界观与叙事

### 背景设定

宇宙并非平滑连续，而是由**时空碎片**拼合而成。主角"时空观测员"穿梭于块状宇宙的裂隙之间，修复错位的时空结构。每修复一个碎片，便解锁一条宇宙底层规律的认知。

### 叙事手法

- **环境叙事**为主：场景本身的物理异常讲述故事
- **NPC** 仅作为概念具象化（双生子佯谬、爱因斯坦/霍金彩蛋）
- **无对话树、无分支叙事**：故事通过关卡推进自然展开
- **三结局**由玩家行为自然触发，无显式选择按钮

### 四大世界主题

| 世界 | 主题 | 物理学分支 | 核心隐喻 |
|------|------|------------|----------|
| W1 洛伦兹平原 | 运动即时间 | 狭义相对论 | 你的速度决定世界流速 |
| W2 引力深渊 | 质量即时间 | 广义相对论 | 引力是时空的弯曲 |
| W3 量子泡沫 | 观测即存在 | 量子引力 | 不确定性是宇宙本质 |
| W4 熵之终焉 | 熵即方向 | 熵与时间箭头 | 时间可能只是幻觉 |

## 三、主角与操作

### 角色

**时空观测员** — 基础几何体 + 斗篷剪影。无具体面部特征，保持抽象以增强代入感。

### 基础操作

| 输入 | 动作 | 说明 |
|------|------|------|
| A/D 或 ← → | 左右移动 | 长按持续加速累积 |
| W 或 空格 | 跳跃 | 世界 2 起获得二段跳 |
| Left Shift | 冲刺 | 速度累积速率 ×3.5 |
| E | 观测 | 世界 3 获得：延长量子裂隙存续 |
| F | 抓取/搬运 | 世界 2 获得：拖拽虫洞口/负能量板 |
| R | 重置谜题 | 全程可用，即时无惩罚 |

### 速度累积系统（世界 1 核心）

```
长按方向键 → ramped_speed 持续增长（最高 980 px/s ≈ 0.98c）
松开方向键 → ramped_speed 清零，速度回落
Shift 冲刺 → 累积速率 ×3.5
抵达光速红线（990 px/s = 0.99c）→ 触发弹回
```

## 四、世界 1：洛伦兹平原

**物理学：狭义相对论 — 时间膨胀、光速不变、光锥因果结构**
**关卡时长：15–20 分钟**

### 核心机制：速度-时间耦合

- 玩家移动速度 ↑ → `scene_time_scale` ↑（场景物体加速）
- 玩家静止/慢行 → 场景正常流速
- **关键规则**：玩家角色本身始终保持即时响应，使用实时 `delta`
- 场景物体（平台、闸门）使用 `TimeManager.scaled_delta(delta)`

**洛伦兹因子公式**：

```
γ = 1 / sqrt(1 - v²/c²)
c = 1000.0 px/s（游戏内光速）
```

**视觉效果**：
- 高速 → 画面蓝移 + 运动方向尺缩
- 低速 → 画面红移
- 接近红线 → 红斑边框脉冲警告

### M1-1：三重时间考验（教学关）

| 要素 | 内容 |
|------|------|
| **物理机制** | 速度-时间耦合（时间膨胀） |
| **学习目标** | 冲刺让场景快进，减速恢复交互 |
| **Zone 1** | 周期闸门 — 提速让闸门加速升降 → 乘隙穿过 |
| **Zone 2** | 移动平台 — 提速让平台快进靠岸 |
| **Zone 3** | 终点时空碎片 — 收集触发完成 |
| **图鉴** | `time_dilation`（时间膨胀） |

### M1-2：光速红线

| 要素 | 内容 |
|------|------|
| **物理机制** | 光速壁垒（光速不变原理） |
| **学习目标** | 光速是宇宙硬上限，蛮力无法穿越 |
| **机制** | 下层被红线壁垒阻断 → 高速冲撞弹回 → 乘速度耦合升降台到上层绕行 |
| **图鉴** | `light_speed_barrier`（光速不变与光速壁垒） |

### M1-3：光锥边界

| 要素 | 内容 |
|------|------|
| **物理机制** | 光锥与因果结构 |
| **学习目标** | 你的未来只能抵达光锥之内 |
| **机制** | 地面虚线划分未来光锥区域 → 走出边界画面灰白冻结 → 3 秒后自动重置至安全位置 |
| **图鉴** | `light_cone`（光锥与因果结构） |

### 隐藏彩蛋

- **双生子小屋**：侧房间可选进入，左侧 NPC 在高速区内快速衰老，右侧正常流速，两者同框对比。

## 五、世界 2：引力深渊

**物理学：广义相对论 — 引力时间膨胀、虫洞、闭合类时曲线**
**关卡时长：25–30 分钟**

### 核心机制 A：引力时间膨胀

- 靠近大质量天体（视觉：画面向引力源扭曲畸变）→ 场景时间变慢
- **玩家操作响应仍然即时**
- 极端引力区（黑洞边缘）：场景近乎冻结，但玩家可自由行动

**引力时间膨胀公式**：

```
t₀ = t_f × sqrt(1 - 2GM/rc²)
r < Schwarzschild 半径 → time_scale = 0（事件视界内时间停滞）
```

### 核心机制 B：双向虫洞与 CTC

- 虫洞成对出现（蓝洞 A、橙洞 B），初始时间同步
- 玩家可将一个洞口搬运至引力区（F 键拖拽）
- 两洞口产生引力时间差 → 穿越 AB 回到"过去"的局部场景
- 过去场景为**预录快照循环播放**，存在"过去的自己"的 NPC 镜像
- 快照通过 `SceneSnapshot` 实现，非全局时间回溯

### 谜题

**M2-1**：悬浮平台周期极短，正常时间无法通过 → 在引力区"等待"让场景减速拉长窗口期

**M2-2（核心 CTC 谜题）**：需开启过去被堵住的门：
1. 正常通过门
2. 搬运虫洞口到引力区
3. 穿越回过去
4. 在门的另一侧开启机关
5. 回到现在，门已开

### BOSS：克尔黑洞

- 不追求传统战斗
- 玩家在旋转潮汐力扭曲中移动
- 利用引力时间膨胀窗口穿过旋转奇环缝隙
- 触碰奇环 → 像素化解体特效 → 检查点重来

### CTC 悖论保护

- 若玩家试图接触"过去的自己" → 画面碎裂特效 + "因果闭环冲突" → 局部谜题重置
- 对应祖父悖论：宇宙禁止自洽性破坏

### 固定图鉴

- `gravitational_time_dilation`（引力时间膨胀）
- `wormhole`（虫洞与爱因斯坦-罗森桥）
- `ctc`（闭合类时曲线 CTC）
- `grandfather_paradox`（祖父悖论）

## 六、世界 3：量子泡沫秘境

**物理学：量子引力 — 卡西米尔效应、真空涨落、时序保护**
**关卡时长：30–35 分钟**

### 核心机制 A：负能量板

- 关卡中分布金属板对，F 键推拢
- 两板距离 < 阈值 → 产生负能量区域（深蓝光晕）
- 玩家可携带负能量球（持续时间有限），注入虫洞以稳定开启
- **非消耗品**：负能量板固定位置，解法是"找到 → 推拢 → 稳定虫洞 → 通过"

### 核心机制 B：量子泡沫裂隙

- 场景随机位置出现瞬时微型虫洞，持续 2–3 秒后湮灭
- **刷新前有 0.5 秒预兆**（粒子向刷新点汇聚）
- 玩家 E 键（观测）：延长裂隙存续（2s → 4s），有冷却
- 将"运气成分"转化为"观察 + 反应 + 资源管理"

### 时序保护陷阱

- 连续 3 次以上时间回溯 → 高能粒子风暴爆发 → 强制重置当前谜题
- 对应霍金时序保护猜想：宇宙禁止宏观时间旅行

### 谜题

**M3-1**：负能量板稳定虫洞 → 穿越封闭空间

**M3-2**：卡量子裂隙刷新时机 + 观测键延长 → 裂隙网络间连续穿越

**M3-3**（综合）：负能量资源管理 + 裂隙时机 + 时序保护边界三者平衡

### 固定图鉴

- `casimir_effect`（卡西米尔效应与负能量）
- `quantum_vacuum`（量子真空涨落）
- `planck_foam`（普朗克尺度时空泡沫）
- `chronology_protection`（时序保护猜想）

## 七、世界 4：熵之终焉

**物理学：热力学第二定律、块状宇宙、时间箭头**
**关卡时长：20–25 分钟**

### 全局机制：单向熵增

- 关卡随时间推进，平台逐渐碎裂崩解
- 视觉从有序 → 像素化瓦解
- 音频从和谐 → 噪音

### 玩家干预

- 消耗"秩序能量"（有限次数，散落关卡中）
- 可暂缓某区域崩坏
- 或将崩坏引导至障碍物炸开新路
- **不违反热力学第二定律**：全宇宙熵仍然净增，仅局部转换

### 三层空间

| 层级 | 名称 | 特征 |
|------|------|------|
| 上层 | 主观时间 | 昼夜循环、物体生灭、标准操作 |
| 中层 | 相对论坐标时空 | 无统一时间流速，各区域时间快慢差异巨大 |
| 底层 | 本源静止空间 | 时间不流动，所有物体静止，过去/现在/未来状态同时可见（同一物体多个时间切片并排） |

### 固定图鉴

- `entropy_arrow`（熵增定律与时间箭头）
- `block_universe`（块状宇宙）
- `wheeler_dewitt`（惠勒-德维特方程）
- `time_illusion`（时间的主观性错觉）

## 八、全局系统

### 时间管理系统（TimeManager）

```
TimeManager（Autoload 单例）
├── scene_time_scale: float      # 场景基准时间倍率（世界 1 = γ）
├── player_lorentz_factor: float # 玩家洛伦兹因子（供视觉效果）
├── player_speed: float          # 玩家当前速率（供音频）
├── redline_ratio: float         # 红线接近度 [0, 1]（供音频/视觉）
│
├── update_from_player_speed()   # 每帧由 Player 调用
├── scaled_delta(delta)          # 场景物体用
├── player_delta(delta)          # 玩家用（原始 delta）
├── calculate_time_scale(body)   # 物体综合时间缩放
└── reset()                      # 谜题重置
```

**关键约束**：
- ❌ 禁止全局修改 `Engine.time_scale`
- ✅ 仅通过 `TimeManager.scaled_delta()` 传递时间膨胀

### 图鉴系统（CodexManager）

- 4 大分类：狭义相对论 / 广义相对论 / 量子引力 / 熵宇宙学
- 每词条：名称 + 1 句通俗解释 + 1 张动态示意图
- 主线谜题必解锁基础词条
- 隐藏词条需探索触发
- 主菜单独立入口

### 玩家行为追踪（PlayerMetrics）

- 无感知记录：CTC 回溯次数、熵减干预次数、底层静止时间、碎片修复数
- 结局由行为统计自然触发（详见[结局系统](#十二结局系统)）

### 音频系统（AudioManager）

- 程序化合成（AudioStreamGenerator）
- 基频随 `scene_time_scale` 变化（80 Hz → 800 Hz）
- 红线警告叠加高频谐波
- 一次性 SFX：弹回、收集、跳跃

## 九、技术架构

### 节点结构（运行时）

```
Level (Node2D)
├── Player (CharacterBody2D) [group: player]
│   ├── CollisionShape2D
│   ├── VisualRoot (Node2D)    ← 尺缩变换目标
│   └── Camera2D
├── [StaticBody2D / Area2D ...]  ← 场景物件
├── KillZone (Area2D)            ← 坠崖检测
├── HUD (CanvasLayer, layer=10)
└── TimeWarpOverlay (CanvasLayer, layer=-1)
```

### 物理层

| 层 | 名称 | 用途 |
|----|------|------|
| 1 | world | 地面、墙壁、障碍物 |
| 2 | player | 玩家角色 |
| 3 | platform | 移动平台 |
| 4 | gate | 周期闸门阻挡 |

### Autoload 加载顺序

```
1. GameState
2. TimeManager
3. CodexManager
4. AudioManager
5. PlayerMetrics
```

### 关键分离原则

```
_process (delta)     → 输入处理（实时）
_physics_process     → 物理计算（实时 delta，不受时间膨胀影响）
场景物体运动         → TimeManager.scaled_delta(delta)
```

## 十、美术与音效

- 手绘卡通 / 低分辨率像素风，便于单人开发
- 角色：基础几何体 + 半透明斗篷剪影

- 调色板：暗色背景 + 霓虹强调色（青 = 时间、红 = 警告、金 = 收集）

## 十一、关卡设计规范

### 谜题设计模板

每个谜题必须填写以下字段：

```
1. 物理机制：本谜题利用的物理原理
2. 学习目标：玩家通过本谜题理解什么概念
3. 解法步骤：最多 3–4 步，避免过度复杂
4. 失败边界：失败后如何重置（无惩罚）
5. 图鉴触发点：解谜后解锁对应词条
```

### 难度梯度

| 世界 | 操作难度 | 认知难度 | 谜题数 | 类型 |
|------|----------|----------|--------|------|
| W1 洛伦兹平原 | 低 | 中 | 3 | 教学引导 |
| W2 引力深渊 | 中 | 中高 | 2 + 1 BOSS | 机制扩展 |
| W3 量子泡沫 | 高 | 高 | 3 | 综合挑战 |
| W4 熵之终焉 | 低 | 高（思辨） | 3 层探索 | 哲学收官 |

### 命名约定

| 类别 | 规范 | 示例 |
|------|------|------|
| 文件 | `snake_case` | `time_dilation.gd` |
| 场景 | `snake_case.tscn` | `level_1_1.tscn` |
| 类名 | `PascalCase` | `TimeManager` |
| 信号 | 过去式动词 | `time_dilated`, `puzzle_reset` |
| 常量 | `UPPER_SNAKE_CASE` | `LIGHT_SPEED` |
| 导出变量 | 分 `@export_category` 组 | `@export_category("Movement")` |

### 禁止事项

- ❌ 玩家操作出现延迟（哪怕为了表现时间膨胀）
- ❌ 随机性过强的谜题解法（量子裂隙必须有预兆提示）
- ❌ 显式的结局选择按钮
- ❌ 大段文字说明物理概念（交给图鉴系统）

## 十二、结局系统

### 触发机制

结局**不由显式按钮选择**，由 `PlayerMetrics` 追踪的行为统计自动判定：

| 结局 | 触发条件 | 含义 |
|------|----------|------|
| **奔赴未来** (TOWARD_FUTURE) | 积极修复时空碎片，世界 4 上层使用近光速装置离开 | 去往未来物理可行 |
| **闭环囚笼** (CLOSED_LOOP_PRISON) | 世界 2+3 中虫洞回溯 ≥ 3 次，系统判定"执着回溯" | 宏观时间旅行受物理禁止 |
| **本源顿悟** (SOURCE_INSIGHT) | 世界 4 底层静止时间 > 60s 且熵减干预 < 3 次 | 底层物理或许没有流动时间 |

### 行为追踪指标

```gdscript
wormhole_loop_count: int = 0        # CTC 回溯次数
entropy_resist_count: int = 0       # 局部熵减干预次数
bottom_layer_idle_time: float = 0.0 # 世界 4 底层静止停留时间
time_fragments_repaired: int = 0    # 修复时空碎片总数
```

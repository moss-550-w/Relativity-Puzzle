## 一、设计铁律

| 编号     | 原则              | 说明                      |
| ------ | --------------- | ----------------------- |
| **P1** | **玩法 = 物理原理**   | 所有机制源自相对论真实结论，不编造科幻设定   |
| **P2** | **操作即时响应**      | 时间效应不影响玩家输入，通过画面/场景时钟表达 |
| **P3** | **失败无惩罚**       | 谜题重置即时，无死亡惩罚，无资源枯竭      |
| **P4** | **科普隐于玩法**      | 无大段文字，图鉴短句+动态示意，会玩就会懂   |
| **P5** | **无战斗、无血量、无升级** | 唯一成长是"理解"。能力由关卡机制赋予     |

## 二、主角与操作

| 输入         | 动作             | 获得时机                 |
| ---------- | -------------- | -------------------- |
| A/D 或 ← →  | 左右移动，长按累积加速    | 初始                   |
| W 或 空格     | 跳跃             | 初始                   |
| Left Shift | 冲刺（累积速率 ×3.5）  | 初始                   |
| **二段跳**    | 空中再次跳跃         | 克尔黑洞 BOSS 关（CP1）持久解锁 |
| F          | 抓取/拖拽（虫洞口、金属板） | World 2 起            |
| E          | 观测（延长量子裂隙存续）   | World 3 起            |
| R          | 重置谜题           | 全程可用                 |

**速度累积系统**：长按方向键 → `ramped_speed` 持续增长（最高 980px/s ≈ 0.98c）→ 光速红线（990px/s = 0.99c）触发弹回。

## 四、世界 2：引力深渊

**物理学**：广义相对论 — 引力时间膨胀、虫洞 CTC、克尔黑洞
**状态**：✅ 全部实现
**新能力**：二段跳（克尔黑洞 BOSS 关解锁，持久生效）

### M2-1：引力时间膨胀

| 要素     | 内容                                                               |
| ------ | ---------------------------------------------------------------- |
| **机制** | 紫色引力区覆盖快速升降平台。正常人无法通过（0.8s 周期）。进入引力区 → 场景减速至 0.25× → 平台变 3.2s 周期 |
| **教学** | 静止在引力区中让减速最大化——冲刺的 γ 会抵消引力效果                                     |
| **图鉴** | `gravitational_time_dilation`                                    |

### M2-2：闭合类时曲线（CTC）

| 要素       | 内容                                                                                          |
| -------- | ------------------------------------------------------------------------------------------- |
| **机制**   | 虫洞对（蓝色 A 固定、橙色 B 可 F 拖拽）。拖 B 入引力区 → 时间差激活 → 进 A 传送到 B + 进入"过去回响" → 门打开 → 按开关 → 返回现在 → 门保持开启 |
| **悖论检测** | 过去态下靠近传送前位置 → 白光悖论爆发 → 解锁祖父悖论图鉴 → 重置                                                        |
| **图鉴**   | `wormhole`、`ctc`、`grandfather_paradox`                                                      |

### BOSS：克尔黑洞

| 要素          | 内容                                                |
| ----------- | ------------------------------------------------- |
| **类型**      | 非战斗——极限环境穿越挑战                                     |
| **Phase 1** | 穿越能层 → 对抗帧拖拽 + 躲避公转碎片 → CP1（解锁二段跳）                |
| **Phase 2** | 内外视界间通道 → 内视界 5s 椭圆形变 → 时间泡等待                     |
| **Phase 3** | 奇环 16 段碰撞体 → 每 3s 开放 2 段间隙 → 穿越 → 核心              |
| **解体**      | 触碰奇环 → 18 像素粒子炸开 → 0.6s 后重生在最近检查点                 |
| **图鉴**      | `kerr_black_hole`、`ergosphere`、`ring_singularity` |

## 五、世界 3：量子泡沫秘境

**物理学**：量子引力 — 卡西米尔效应、真空涨落、时序保护
**状态**：✅ 全部实现
**新能力**：E 键观测（延长量子裂隙）

### M3-1：卡西米尔效应

| 要素     | 内容                                                                     |
| ------ | ---------------------------------------------------------------------- |
| **机制** | 封闭空间只能通过不稳定虫洞进入。两块金属板（F 键拖拽）推拢 < 100px → 板间产生蓝色负能量光柱 → 虫洞从橙闪变为蓝稳 → 可穿越 |
| **图鉴** | `casimir_effect`                                                       |

### M3-2：量子裂隙网络

| 要素      | 内容                                                           |
| ------- | ------------------------------------------------------------ |
| **机制**  | 三房间隔离，4 对量子裂隙交错出现。裂隙生命周期：预兆(0.5s)→打开(2s)→坍缩。E 键延长 +2s（冷却 3s） |
| **时间表** | F1(0s, A→B)、F2(2.5s, A→C直通)、F3(5s, B→C主线)、F4(7s, B→C备选)      |
| **图鉴**  | `quantum_vacuum`                                             |

### M3-3：时序保护

| 要素       | 内容                                                                |
| -------- | ----------------------------------------------------------------- |
| **机制**   | 三机制综合：负能量板稳定裂隙 + E 键观测延长 + 时序保护上限                                 |
| **时序保护** | 左上角 3 个菱形标记，每次 E 干预 +1。计数 ≥3 → 全屏金红粒子风暴 → 2s 后谜题重置。15s 未干预自动衰减 -1 |
| **最优解**  | 负能量稳定 F1（0 干预）→ E 延 F2（1 干预）→ 到达                                  |
| **图鉴**   | `chronology_protection`                                           |

## 六、世界 4：熵之终焉

**物理学**：热力学第二定律、块状宇宙、惠勒-德维特方程
**状态**：✅ 全部实现

### 上层：熵之斜坡

| 要素       | 内容                                                              |
| -------- | --------------------------------------------------------------- |
| **机制**   | 全局熵值 \[0,1] 线性递增（\~125s 到 1.0）。3 个熵增平台渐进崩解（完整→裂纹→崩解→消失），碰撞体同步缩小 |
| **秩序能量** | 3 个金色光点可收集，每次消耗回退熵 0.12（约 15s）                                  |
| **昼夜**   | 90s 周期正弦暖橙（昼）↔ 深蓝（夜）CanvasLayer 叠加                              |
| **图鉴**   | `entropy_arrow`                                                 |

### 中层：时间的碎片

| 要素       | 内容                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------ |
| **机制**   | 6 个时区（绿 1×、红 0.05×、蓝 5×、紫 0.3×、金 3×、灰 0×）水平排列。进入时区 → `TimeManager.gravity_factor` 平滑 tween 到该区倍率 |
| **碎片**   | A(红区·极慢平台 5s 周期)、B(蓝区·极快平台 4s 周期)、C(灰区·完全冻结·靠惯性)                                                 |
| **熵增暂停** | 中层不受上层崩解影响                                                                                       |
| **图鉴**   | `block_universe`                                                                                 |

### 底层：本源静止空间

| 要素     | 内容                                                        |
| ------ | --------------------------------------------------------- |
| **机制** | 时间完全静止。3 组时间切片——同一物体以 5 个时间副本平铺（红\[过去]→白\[现在]→蓝\[未来]）     |
| **独白** | 4 段字幕分别于 10s/30s/60s/90s 淡入："时间不流动……惠勒-德维特方程中，时间消失了……"    |
| **结局** | 120s 后自动触发 `PlayerMetrics.determine_ending()` → 冻结 + 结局字幕 |
| **图鉴** | `wheeler_dewitt`（60s）、`time_illusion`（90s）                |

## 七、全局系统

### Autoload 加载顺序

| 顺序 | 名称              | 职责                            |
| -- | --------------- | ----------------------------- |
| 1  | `GameState`     | 世界/关卡索引、暂停、二段跳解锁、谜题重置         |
| 2  | `TimeManager`   | 场景时间缩放（速度γ × 引力因子）、玩家实时 delta |
| 3  | `CodexManager`  | 图鉴解锁、词条数据（16 条）               |
| 4  | `AudioManager`  | 程序化音频合成（AudioStreamGenerator） |
| 5  | `PlayerMetrics` | 行为追踪：CTC 次数、熵减干预、底层静止时间、结局判定  |
| 6  | `EntropySystem` | 全局熵值 \[0,1]、秩序资源、里程碑信号        |

### TimeManager 计算公式

```
scene_time_scale = γ (player_lorentz_factor)
gravity_factor   = 1.0 (默认) / 时区倍率 (中层) / 引力区倍率 (W2)
scaled_delta     = delta × scene_time_scale × gravity_factor
player_delta     = delta (始终实时)
```

## 十、结局系统

结局由 `PlayerMetrics` 追踪的行为统计在底层 120s 后自动判定：

| 结局       | 触发条件                         | 字幕                       |
| -------- | ---------------------------- | ------------------------ |
| **奔赴未来** | 默认（修复碎片 ≥ 3，CTC < 3，未满足其他条件） | "你选择向前。未来永远是开放的。"        |
| **闭环囚笼** | CTC 回溯 ≥ 3 次                 | "你执着于回溯过去，却被困在了因果的循环之中。" |
| **本源顿悟** | 底层静止 > 60s 且熵减干预 < 3         | "时间从未流动。你终于理解了。"         |

## 一、校验原则

### 分级标准

| 级别 | 含义 | 处理方式 |
|------|------|----------|
| **精确** | 游戏行为与物理公式定量一致 | 代码直接实现公式 |
| **定性** | 方向/趋势正确，但数值缩放适配游戏性 | 标注缩放因子与边界 |
| **隐喻** | 通过玩法传达概念直觉，不完全对应真实物理 | 图鉴中标注"此为简化模型" |
| **假说** | 基于理论假说/前沿物理，尚未实验证实 | 图鉴中标注"此为理论假说，尚未实验证实" |

### 校验规则

1. 不可为了游戏性编造与真实物理矛盾的行为
2. 简化必须**可解释**：知道哪里简化了、为什么可以简化
3. 图鉴词条的通俗解释必须**定性正确**
4. 假说性内容必须标注，不得冒充已证实理论
5. 每个机制的代码实现必须能追溯到本文件中的公式

## 二、狭义相对论（世界 1）

### 2.1 时间膨胀（Time Dilation）

**真实物理**：

```
Δt' = γ × Δt₀

γ = 1 / √(1 − v²/c²)

其中：
  Δt₀  = 静止参考系中的时间间隔（固有时）
  Δt'  = 运动观察者测得的时间间隔
  v    = 相对运动速度
  c    = 真空中光速 ≈ 3.0 × 10⁸ m/s
```

**物理要点**：
- v = 0 → γ = 1（无时间膨胀）
- v → c → γ → ∞（时间无限膨胀）
- 有质量物体永远无法达到 c（需无穷能量）
- 效果是对称的：A 看 B 的时间变慢，B 看 A 的时间也变慢

**游戏实现**（`speed_time_coupling.gd`）：

```gdscript
const LIGHT_SPEED: float = 1000.0  # 游戏内光速 (px/s)
const SPEED_REDLINE: float = 0.99 * LIGHT_SPEED  # 红线 = 990 px/s

static func lorentz_factor(speed: float) -> float:
    if speed < 1.0:
        return 1.0
    var ratio: float = speed / LIGHT_SPEED
    if ratio >= 1.0:
        return INF  # 触发弹回，不允许到达 c
    return 1.0 / sqrt(1.0 - ratio * ratio)
```

**简化假设**：
| 简化 | 真实物理 | 游戏处理 | 合理性 |
|------|----------|----------|--------|
| c = 1000 px/s | c = 3×10⁸ m/s | 游戏尺度下重新标度 | 相对比值不变，定性正确 |
| 红线 = 0.99c | 无硬边界（连续趋近） | 0.99c 触发弹回 | 表达"接近 c 极困难"，非虚假 |
| 单向时间膨胀 | 对称效应 | 仅场景加速，玩家时间不变 | **游戏设计铁律 P2**：操作必须即时 |
| 忽略同时性相对性 | 同时性是相对的 | 不实现 | Phase 1 不必要，过于复杂 |

**准确性评级**：**定性**（公式精确，但 c 值缩放 + 对称性简化）

**校验清单**：
- [x] `lorentz_factor()` 公式与真实物理一致
- [x] v → c 时 γ → ∞，触发弹回而非穿越
- [x] v = 0 时 γ = 1.0
- [ ] 需验证：`scene_time_scale = γ` 时，场景物体的速度变化倍数是否定性合理

### 2.2 光速不变与光速壁垒

**真实物理**：
- 真空中光速在任何惯性参考系中恒定
- 相对论速度叠加公式：u' = (u + v) / (1 + uv/c²)，永远 < c
- 有质量物体加速到 c 需要无限能量

**游戏实现**（`player.gd` + `redline_barrier.gd`）：

- 玩家速度累积上限 = `max_speed`（980 px/s < 990 红线）
- 抵达红线 → 强制弹回 + `redline_bounced` 信号 + 全屏红移闪光
- 红线壁垒为 `StaticBody2D`，物理碰撞不可穿透

**简化假设**：
| 简化 | 合理性 |
|------|--------|
| 用硬碰撞代替渐近趋近 | 游戏需要清晰的"失败"反馈。真实物理中也需要无限能量，游戏用弹回表达"不可逾越" |
| 弹回速度 = 0.7 × 红线速度 | 仅影响手感，不改变物理定性结论 |

**准确性评级**：**隐喻**（核心结论"不可达"正确，但实现方式为游戏化隐喻）

**校验清单**：
- [x] 无任何机制允许玩家速度 ≥ `SPEED_REDLINE`（990）
- [x] 红线壁垒物理碰撞 100% 不可穿越
- [ ] 需验证：红线弹回后玩家累积速度清零，不会立即再次触发

### 2.3 尺缩效应（Length Contraction）

**真实物理**：

```
L = L₀ / γ

其中：
  L₀ = 物体在静止参考系中的长度（固有长度）
  L  = 运动观察者测得的长度
```

仅运动方向上的长度收缩，垂直方向不受影响。

**游戏实现**（`player.gd._update_length_contraction()`）：

```gdscript
var squeeze: float = clampf(1.0 / gamma, contraction_min_scale, 1.0)
_visual_root.scale.x = squeeze  # 横向压缩
_visual_root.scale.y = 1.0      # 纵向不变
```

**简化假设**：
| 简化 | 合理性 |
|------|--------|
| 仅视觉根节点变形，碰撞体不变 | 不改变玩法，纯视觉效果 |
| 下限 `contraction_min_scale = 0.1` | 避免 γ 极大时玩家缩成一个点不可见 |
| 横向 = 运动方向（仅允许水平移动） | World 1 无纵向速度累积 |

**准确性评级**：**定性**（公式正确，应用方向正确）

### 2.4 光锥与因果结构

**真实物理**：

```
时空中的事件 E，其未来光锥定义为：
  从 E 出发，以光速或以下可能到达的所有时空点的集合

光锥边界由 ds² = 0 定义（类光分离）：
  ds² = −c²dt² + dx² + dy² + dz² = 0

类时分离 (ds² < 0)：因果可达（光锥内）
类光分离 (ds² = 0)：光锥边界
类空分离 (ds² > 0)：因果不可达（光锥外）
```

**游戏实现**（`light_cone_boundary.gd`）：

- Area2D 定义"未来光锥安全区"
- 玩家离开区域 → 冻结 + 灰白 → 3 秒后重置
- 教学：锥外不可达

**简化假设**：
| 简化 | 合理性 |
|------|--------|
| 静态矩形代替真实光锥（45° 斜面） | 2D 平台游戏的空间/时间轴不同于闵氏时空。真实光锥在 (x, t) 图中是 45° 线，但游戏只有 x-y 空间 |
| 空间边界代替时空边界 | 游戏无法表达"先慢后快仍在锥内"的时空路径概念 |
| 冻结 = 因果不可达 | 隐喻：你无法与锥外事件产生因果关联 |

**准确性评级**：**隐喻**（概念正确——因果边界存在且不可逾越，但几何实现为空间隐喻而非时空几何）

**图鉴提示**：标注"真实光锥在时空中呈 45° 锥形，本关将其简化为空间边界以传达核心直觉"

### 2.5 双生子佯谬（Twin Paradox）

**真实物理**：
- 双胞胎 A 留在地球，B 以近光速往返
- B 返回时比 A 年轻（因为 B 经历了加速/非惯性运动）
- 不是佯谬：狭义相对论完全可以解释（B 经历了非惯性参考系变换）

**游戏实现**：隐藏彩蛋 NPC，左侧高速区 NPC 快速衰老，右侧正常流速 NPC，同框对比。

**准确性评级**：**定性**（方向正确——高速者经历的时间少）

## 三、广义相对论（世界 2）

### 3.1 引力时间膨胀

**真实物理**：

```
施瓦西度规（球对称非旋转质量外部）：

t₀ = t_f × √(1 − rₛ/r)

其中：
  t₀    = 距质心 r 处的固有时流速
  t_f   = 无穷远处的坐标时流速
  rₛ    = 2GM/c²（史瓦西半径）
  r     = 距质心的径向距离
  G     = 引力常数 ≈ 6.674 × 10⁻¹¹ N·m²/kg²
  M     = 中心质量
```

**物理要点**：
- r → ∞：时间流速正常（t₀ → t_f）
- r → rₛ：时间流速趋近于 0（事件视界边界）
- r < rₛ：事件视界内，公式不再适用（需克尔度规或完整广义相对论）
- 与速度时间膨胀不同：引力时间膨胀是**绝对的**，不是对称的

**游戏实现**（`gravity_time_dilation.gd`，待实现）：

```gdscript
func get_gravitational_time_dilation(position: Vector2, mass: float, center: Vector2) -> float:
    var r = position.distance_to(center)
    if r < SCHWARZSCHILD_RADIUS:
        return 0.0  # 事件视界内时间停滞
    return sqrt(1.0 - (2.0 * G * mass) / (r * C_SQUARED))
```

**简化假设**：
| 简化 | 合理性 |
|------|--------|
| 牛顿引力势近似（用施瓦西外解） | 非旋转、球对称质量的外部解是精确的 |
| 2D 空间中 r = 欧几里得距离 | 实际时空是弯曲的，"距离"本身被引力改变。游戏用空间距离代理 |
| G 和 M 合并为可调参数 | 玩家不需要知道真实 G/M 值，只需定性感受"越近越慢" |
| 弱场区域用近似公式 | 远离视界时近似良好 |

**准确性评级**：**定性**（公式使用施瓦西外解——精确解，但距离度量为简化的 2D 欧几里得距离）

### 3.2 虫洞（爱因斯坦-罗森桥）

**真实物理**：
- 爱因斯坦场方程的一个解（爱因斯坦-罗森桥，1935）
- 理论上是连接时空两点的"捷径"
- 经典广义相对论中虫洞不稳定（会立即坍缩）
- 需要"奇异物质"（负能量密度）维持开放
- 至今无观测证据；维持宏观虫洞需要巨大负能量

**游戏实现**（`wormhole.gd` + `wormhole_portal.gd`，待实现）：

- 成对虫洞（蓝 A、橙 B）
- 将一洞口搬运至引力区 → 两洞口产生时间差
- 穿越产生时间差的虫洞对 → 回到过去（局部场景快照）

**简化假设**：
| 简化 | 合理性 |
|------|--------|
| 可搬运的虫洞口 | 真实虫洞需要奇异物质维持，无法随意移动。游戏将其作为谜题工具 |
| 精确的"回到过去" | 真实的虫洞时间差取决于引力势差和穿越速度，数值上难以精确到"恰好回到门的另一侧" |
| 快照而非全局时间回溯 | **合理**——避免了全局时间倒流的物理悖论 |

**准确性评级**：**假说**（虫洞本身是场方程的数学解，但可穿越虫洞需要负能量——未经实验证实）

**图鉴提示**：必须标注"爱因斯坦-罗森桥是广义相对论的数学解，但可穿越虫洞需要负能量物质，目前尚未被实验证实"

### 3.3 闭合类时曲线（CTC）与祖父悖论

**真实物理**：
- CTC 是时空中回到自身过去的闭合路径
- 哥德尔宇宙（旋转宇宙）中存在 CTC
- 大多数物理学家认为 CTC 在量子引力层面被禁止（时序保护猜想）
- 祖父悖论：若回到过去杀死祖父 → 逻辑矛盾
- Novikov 自洽性原则：任何时间旅行必与历史自洽

**游戏实现**（`ctc_handler.gd`，待实现）：

- 虫洞 CTC 回溯 = 场景快照重建
- 玩家可与过去场景交互（开启当时关着的门）
- 接触"过去的自己" → 悖论检测 → 谜题重置

**简化假设**：
| 简化 | 合理性 |
|------|--------|
| CTC 通过虫洞实现 | 这是 CTC 的标准理论模型之一 |
| 悖论 → 重置（而非逻辑崩溃） | 游戏性需要。真实物理中悖论如何解决无人知晓 |
| Novikov 自洽性通过"快照不能改变历史"表达 | 与自洽性精神一致：你只能做已发生的事 |

**准确性评级**：**假说**（CTC 理论存在但无实验证据，悖论解决方案均为推测）

### 3.4 克尔黑洞

**真实物理**：
- 旋转黑洞（克尔解，1963）

## 四、量子引力（世界 3）

### 4.1 卡西米尔效应与负能量

**真实物理**：

```
卡西米尔力（两平行理想导体板间）：

F/A = −π²ħc / (240 × d⁴)

其中：
  F/A = 单位面积上的力（负值 = 吸引力）
  ħ   = 约化普朗克常数 ≈ 1.055 × 10⁻³⁴ J·s
  d   = 两板间距
```

**物理要点**：
- 真空中存在量子涨落（虚粒子对不断创生湮灭）
- 两板间仅允许特定波长的涨落模式存在
- 板外涨落 > 板内 → 产生内向压力 → 板被推拢
- 板间能量密度低于真空零点能 → "负能量"
- 1997 年实验精确验证（Lamoreaux，精度 5%）

**游戏实现**（`negative_energy.gd` + `negative_energy_plate.gd`，待实现）：

- 金属板对用 F 键推拢
- 距离 < 阈值 → 产生负能量区域
- 携带负能量球注入虫洞以稳定开启

**简化假设**：
| 简化 | 合理性 |
|------|--------|
| 卡西米尔效应产生宏观"负能量球" | 真实负能量密度极低（~10⁻⁷ J/m³ at d=1μm），不足以稳定宏观虫洞。但传达概念正确 |
| 两板推拢即生效 | 真实的力仅在纳米尺度显著。游戏放大到宏观尺度 |
| 负能量可"携带" | 真实负能量是区域性质，不能打包带走。为游戏性简化 |

**准确性评级**：**定性**（卡西米尔效应是证实的量子效应，"真空不空"的正确传达。但负能量稳定虫洞是**假说**）

**图鉴提示**："卡西米尔效应已被实验证实。但其产生的负能量是否足以稳定宏观虫洞，是目前理论物理的开放问题。"

### 4.2 量子真空涨落

**真实物理**：

```
能量-时间不确定性原理：

ΔE × Δt ≥ ħ/2

虚粒子对在 Δt ~ ħ/(2ΔE) 内湮灭，遵守能量守恒
```

**物理要点**：
- 真空中虚粒子对不断创生和湮灭（存在时间由不确定性原理限制）
- 虚粒子不可直接观测，但其效应可测量（如卡西米尔效应、兰姆位移）
- 霍金辐射：视界附近一对虚粒子分离，一个落入黑洞，一个逃逸为实粒子

**游戏实现**（`quantum_fissure.gd` + `quantum_fissure_spawner.gd`，待实现）：

- 随机刷新瞬时微型虫洞（裂隙），持续 2–3 秒
- 刷新前 0.5 秒粒子预兆汇聚
- 观测键（E）延长存续 2 秒

**简化假设**：
| 简化 | 合理性 |
|------|--------|
| 量子涨落 → 宏观可见裂隙 | 普朗克尺度涨落（~10⁻³⁵ m）在游戏中放大。隐喻性表达 |
| 观测延长存续 | 对应"观测者效应"的隐喻——量子系统在被观测时行为改变 |
| 0.5 秒预兆 | 游戏公平性要求。真实量子涨落是真正的随机，无预兆 |

**准确性评级**：**隐喻**（量子涨落真实存在，但宏观虫洞裂隙是隐喻。预兆机制是为可玩性添加的游戏设计，非物理要求）

### 4.3 时序保护猜想

**真实物理**：
- 霍金（1992）提出：物理定律禁止宏观时间旅行
- 量子真空涨落在 CTC 形成时会发散 → 能量密度趋于无穷 → 破坏 CTC
- "大自然讨厌时间机器"

**游戏实现**（`ctc_handler.gd`，待实现）：

- 连续 ≥ 3 次 CTC 回溯 → 高能粒子风暴 → 强制重置谜题

**准确性评级**：**假说**（霍金的时序保护猜想尚未被证明或证伪。在游戏中作为"软上限"机制使用是合理的隐喻）

## 五、熵与时间箭头（世界 4）

### 5.1 热力学第二定律

**真实物理**：

```
dS/dt ≥ 0  （孤立系统）

其中 S = 系统的熵（无序度）

微观定义（玻尔兹曼）：
  S = k_B × ln(W)

其中：
  k_B = 玻尔兹曼常数 ≈ 1.381 × 10⁻²³ J/K
  W   = 微观状态数
```

**物理要点**：
- 孤立系统总熵永不减少
- **局部**可以减熵（如生命体），但需要外部能量输入
- 宇宙整体熵增不可逆
- 熵增 = 时间之箭的热力学来源

**游戏实现**（`entropy_system.gd`，待实现）：

- 全局熵随时间递增
- 平台逐渐碎裂崩解
- 玩家消耗"秩序能量"可暂缓崩坏或引导崩坏至障碍物

**简化假设**：
| 简化 | 合理性 |
|------|--------|
| 熵增可视化为平台崩解 | 真实的熵增是微观态数的增加，不可直接"看到"。视觉化是合理隐喻 |
| "秩序能量"可局部干预 | 对应真实物理：局部减熵需要能量输入（如冰箱耗电），宇宙总熵仍增 |
| 线性熵增速 | 真实系统熵增速通常非线性，但游戏时长（~20 分钟）内线性近似合理 |

**准确性评级**：**定性**（方向 100% 正确——熵不可逆增。局部干预不违反全局增熵的约束显式保留。）

### 5.2 块状宇宙

**真实物理**：
- 块状宇宙（Block Universe）是闵氏时空的自然推论
- 过去、现在、未来是四维时空中的不同"切片"，都同样真实存在
- "现在"的特殊性可能是人类意识的错觉（而非物理实在）
- 与"流动的时间"（A 理论）对立的是"块状时间"（B 理论）

**游戏实现**（World 4 底层）：

- 静止空间中，同一物体不同时刻的状态同时可见
- 过去/现在/未来的"切片"并排展示

**准确性评级**：**假说**（块状宇宙是相对论时空观的合理推论，但"时间是否真的流动"是哲学/物理学交叉的开放问题。）

**图鉴提示**：必须标注"块状宇宙是狭义/广义相对论的数学推论之一，但时间的本质是否为'块状'仍是物理学与哲学的交叉开放问题。"

### 5.3 惠勒-德维特方程

**真实物理**：

```
Ĥ|Ψ⟩ = 0

其中：
  Ĥ     = 哈密顿约束算符（量子引力中的总能量算符）
  |Ψ⟩   = 宇宙的波函数
```

**核心结论**：时间变量 t 从方程中消失——在量子引力层面，"时间"可能不是基本量。

**物理要点**：
- 这是量子引力（正则量子化）的核心方程
- 方程不包含时间变量 → "时间"可能是宏观涌现量
- 类似于温度：微观层面原子没有"温度"，温度是大量原子的统计涌现
- 目前尚无实验验证（需要普朗克尺度探测）

**游戏实现**（World 4 底层叙事 + 图鉴）：

- 底层空间中无时间流动，体现"时间不基本"的哲学意涵

**准确性评级**：**假说**（惠勒-德维特方程是正则量子引力的真实方程，但其物理诠释——"时间不存在"——是推测性的。需在图鉴中标注。）

**图鉴提示**：必须标注"惠勒-德维特方程是量子引力的候选方程之一，其'时间消失'的解读存在争议，尚未实验证实。"

## 六、跨世界物理一致性

### 6.1 时间膨胀叠加规则

当多个时间膨胀来源同时存在（速度 + 引力），实际物理中是**非线性叠加**：

```
真实物理：
  γ_total ≠ γ_speed × γ_gravity
  
  需从度规出发计算（施瓦西度规 + 运动项）
```

**游戏处理**（`TimeManager.calculate_time_scale()`）：

```
当前（World 1）：仅速度膨胀
  scale = γ_speed

World 2+：乘法叠加
  scale = γ_speed × γ_gravity × γ_entropy
```

**简化说明**：乘法叠加是弱场低速下的近似。在强引力 + 近光速极端情况会偏离真实物理。游戏中的极端场景（同时近黑洞 + 近光速）几乎不会出现，近似可接受。

### 6.2 因果性贯穿

所有世界的谜题设计必须满足一个统一约束：**无超光速信息传递**。

| 世界 | 因果约束 | 实施方式 |
|------|----------|----------|
| W1 | 光锥内可达 | `light_cone_boundary.gd` |
| W2 | CTC 不得破坏自洽性 | Novikov 自洽性约束 + 悖论检测 |
| W3 | 时序保护（禁止宏观 CTC） | ≥ 3 次回溯强制截断 |
| W4 | 熵增单向性 | 全局熵单调递增，不可回退 |

## 七、常见错误与修正

### 7.1 常见概念混淆

| 错误说法 | 正确说法 | 解释 |
|----------|----------|------|
| "速度越快，时间越慢" | "运动观察者测得运动物体的时间流逝比静止参考系慢" | 时间膨胀是**相对的**：你看别人的钟慢了，别人看你的钟也慢了。没有绝对的"谁更慢"。 |
| "引力时间膨胀是因为引力'拉'住了时间" | "时空弯曲导致不同位置的固有时流速不同" | 是**时空几何**效应，不是力。 |
| "虫洞是黑洞" | "虫洞是爱因斯坦-罗森桥，连接两个时空区域。黑洞是引力坍缩的终态。" | 两者不同。史瓦西虫洞（爱因斯坦-罗森桥）连接两个宇宙，但不可穿越。 |
| "熵是混乱度" | "熵是系统微观状态数的对数度量" | "混乱"是直观但不精确的描述。更准确的直觉：熵 = 关于系统微观状态的**信息缺失**。 |
| "双生子佯谬是狭义相对论的矛盾" | "双生子佯谬不是矛盾——广义相对论或加速运动的狭义相对论分析都能正确解释" | "佯谬"意为"看似矛盾，实际不矛盾"。 |

### 7.2 应在图鉴中标注的内容

以下概念属于**假说/推测/开放问题**，图鉴文案必须标注：

1. **可穿越虫洞**：需要负能量，尚未实验证实
2. **CTC/时间旅行**：是否被物理定律允许尚不确定
3. **时序保护猜想**：霍金提出，未被证明
4. **块状宇宙**：是时空几何的哲学诠释之一，非唯一解释
5. **惠勒-德维特方程与"时间不存在"**：量子引力的候选理论之一，诠释有争议
6. **量子引力本身**：目前无完整的、实验验证的量子引力理论
